Первый публичный выпуск Limbo Keyboard.

**Файл:** `Limbo-1.0.0-universal.apk` · 950 КБ · Android 8.0+ (API 26) · `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`

```bash
adb install -r Limbo-1.0.0-universal.apk
```

Затем: **Настройки → Система → Языки и ввод → Экранная клавиатура → Limbo**, там же выбрать её клавиатурой по умолчанию. Приложение Limbo открывает этот экран одной кнопкой и показывает, на каком шаге вы находитесь.

## Что внутри

**Ввод**
- 8 языков с привычными раскладками: English, Русский, Deutsch, Français, Español, Italiano, Türkçe, Polski
- прощающая зона: нажатие рядом с клавишей всё равно срабатывает, ширина регулируется
- увеличение буквы над пальцем, акценты на долгом нажатии, свайп по пробелу для курсора
- заглавные после точки, умный пробел, двойной пробел → точка

**Оформление**
- 30 готовых тем и студия, где меняется каждый цвет и радиус
- шесть характеров клавиш: матовое, мягкие, плотные, контур, минимал, кристалл
- мутность, свет по кромке, тени, разрядка, высота — всё живьём, с мгновенным превью
- светлая и тёмная версия любого оформления одним переключателем

**Буфер обмена**
- история до 200 записей вместо одной, закрепление, определение типа: ссылка, почта, номер, текст
- всё на устройстве, переживает перезапуск

**Знакомство**
- восемь шагов: включение, языки, раскладка, настроение, буфер, проверка на живой клавиатуре

## Почему один APK, а не четыре

В клавиатуре нет нативного кода: вся логика и вся отрисовка — Kotlin, который компилируется в один
`classes.dex`, а DEX не зависит от архитектуры процессора. Файлы «под arm64» и «под x86_64»
получились бы побайтово одинаковыми, поэтому релиз содержит один universal APK, который работает
на любой архитектуре.

Скрипты сборки уже умеют делиться на ABI: `toolchain/build.sh` включает шаг сплитов сам, как только
в пакете появляется `lib/<abi>/`, а в Gradle для этого есть `splits { abi { … } }` за переменной
`LIMBO_ABI_SPLITS=1`. Подробности — [`docs/RELEASE.md`](https://github.com/vinafortx/LimboKeyboard/blob/main/docs/RELEASE.md).

## Сборка из исходников

```bash
./toolchain/build.sh --release   # aapt2 → kotlinc → d8 → zipalign → apksigner
./gradlew assembleRelease        # то же самое через Gradle
```

## Приватность

Ни одного разрешения, кроме `VIBRATE`. Нет `INTERNET`, нет аналитики, нет рекламы.
История буфера, словарь и настройки лежат только на устройстве.
